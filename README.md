# 九间 · Sudoku

简洁的原创数独网页小游戏，适配手机和电脑，无运行依赖。

**在线游玩：[九间](https://qinheart.github.io/jiujian-sudoku/)**

## 功能

- 实时随机出题，每题经过唯一解和基础逻辑可解检查。
- 居中棋盘，下方数字键盘；提供笔记、擦除、撤销及即时错误提示。
- 主页可以开始新一局或继续本设备上次的游戏。
- 暂停后棋盘清晰可见，停止计时和填写；也可以选择遮罩休息。
- 数字键的“余”表示还需正确填写的数量，“还剩”包括未填和待改正的格子。
- 进度保存在浏览器本地，不上传，不跨设备同步。

## 本地运行

直接打开 `index.html`，或执行 `python3 -m http.server 4173` 后访问 `http://localhost:4173`。无需 npm install。HTTP 环境通过 Web Worker 后台生成题目，直接打开文件时使用本地生成路径。

键盘：1–9 输入；方向键移动；N 切换笔记；Backspace / Delete 擦除；Ctrl / Command + Z 撤销。笔记不判错，正式数字按唯一解立即校验。

## 实现与验证

生成器、求解器及界面均自行编写，未使用第三方数独引擎。随机回溯先生成完整答案，再逐格挖空并检验唯一解；显性单数、隐性单数逻辑筛选日常练习题。当前会话对最近 20 道题去重，不承诺跨会话绝不重复。

运行 `node test-engine.cjs`，对 100 道随机题用独立求解器交叉验证唯一解，并检查给定数字、答案和基础逻辑可解性。

## GitHub Pages

使用 `main` 分支根目录发布，无需自定义 GitHub Actions 工作流。页面使用相对资源路径，适用于项目子路径。

浏览器以域名和路径等信息隔离本地存储；在本地地址保存的游戏不会自动迁移到 Pages 地址。
